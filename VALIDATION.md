## GitHub / physical-device limits

The push/manual workflow still runs unit tests and assembles the APK as `mileage-tracker-debug`; it now also uploads synthetic `ui-previews`. Consult the latest review-branch checks for remote CI status. No merge or environment publication is performed by these changes.

A physical Nothing Phone 2a was not connected. First-launch airplane-mode behavior, native picker providers, keyboard/insets, large-font rendering and scrolling performance on that phone still require the README checklist. Robolectric checks do not establish physical-device behavior.

Normal signed app updates migrate Room data without deleting it. GitHub debug APKs may be signed with different temporary keys, so export a full JSON backup outside app storage before replacing an installed debug APK; README explains the reinstall/restore path if Android rejects the signature.
